## Overview

* *Purpose:* Contains measurements of five cells selected from a fluorescence image using Fiji.
* *Cell Selection:* The Freehand Selection Tool was used to manually outline each cell, and the selected regions were organized using the ROI (Region of Interest) Manager.
* *Measurements:* Fiji's measurement function was used to obtain cell area, mean fluorescence intensity, circularity, aspect ratio, minimum intensity, and maximum intensity.
* *Data Export:* The Results table was exported as a CSV file for further analysis in R.
* *Use in Analysis:* The measurements were used to calculate summary statistics and generate graphs comparing cell size, shape, and actin-associated fluorescence intensity.
