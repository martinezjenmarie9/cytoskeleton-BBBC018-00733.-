## Overview

* *Purpose:* Contains the summary statistics calculated from the five cell measurements obtained using Fiji.
* *Data Included:* Records the selected phenotype, image ID, number of cells measured, mean cell area, mean circularity, mean aspect ratio, and mean fluorescence intensity.
* *Data Processing:* The summary values were calculated using the R script scripts/analyze_cells.R.
* *Data Export:* The summary statistics were saved as a CSV file for convenient storage, viewing, and reporting.
* *Use in Analysis:* Provides a concise summary of the measured cells' morphology and actin-associated fluorescence intensity, supporting the interpretation of the generated graphs and the comparison of cell characteristics.
